# Workshop Dock

Локальный браузер модов Steam Workshop. При запуске открывается каталог Kenshi (Steam App ID 233860) с рейтингом за всё время. Каталог и поиск работают через публичные страницы Steam и API, без ключа API и без аккаунта.

## Windows

[Скачайте WorkshopDock.exe](https://github.com/arcueidnyan/ProTools/raw/refs/heads/windows-download/WorkshopDock.exe) и откройте двойным кликом. Workshop Dock сам откроет браузер. Когда закончите, нажмите OK в окне Workshop Dock.

Python уже внутри. Если для мода нужна ZIP-загрузка, приложение само скачает SteamCMD с сервера Valve и сохранит его для следующих запусков. Для поиска и скачивания нужен интернет.

## Запуск из исходников

1. Распакуйте архив. Нужен Python 3.10 или новее. Дополнительных пакетов Python нет.
2. В папке проекта запустите `python server.py` (в Linux или macOS обычно `python3 server.py`, в Windows также `py -3 server.py`).
3. Откройте http://127.0.0.1:8765. Для поиска по другой игре выберите «Другая игра» и введите её Steam App ID. Карточку можно открыть и по ссылке на предмет или его Workshop ID.

## Скачивание

Если Steam публикует прямую ссылку, кнопка откроет оригинальный файл. При запуске из исходников для остальных модов установите [SteamCMD](https://developer.valvesoftware.com/wiki/SteamCMD). Добавьте его в PATH или укажите путь к исполняемому файлу в переменной среды `STEAMCMD` перед запуском сервера.

Сервер использует `login anonymous` и `workshop_download_item`, после чего выдаёт ZIP с содержимым мода. Игра может требовать вход или лицензию. В этом случае SteamCMD может отклонить загрузку. Коллекции и зависимости автоматически не скачиваются.

Сервер слушает только 127.0.0.1. Порт можно указать в переменной среды `PORT`. SteamCMD может хранить собственный кеш Workshop в каталоге установки.

Сборка EXE из исходников для Windows x64: `python windows/build.py WorkshopDock.exe` (нужны Python и Go).
