# Поле

«Поле» — персональная веб-доска для заметок и простых схем. Приложение не вводит лимит на количество досок. Данные занимают место на диске сервера. Доска, отправляемая при автосохранении, может занимать до 8 МиБ в JSON.

## Демо для Windows

[Скачать PoleDemo.exe](https://github.com/arcueidnyan/ProTools/raw/refs/heads/main/pole/PoleDemo.exe) для Windows 10/11 x64. Запустите файл двойным щелчком. Приложение откроет браузер на http://localhost:8080. Консоль должна оставаться открытой, пока вы работаете с доской. Данные этой сборки сохраняются в `%APPDATA%\PoleDemo\boards.json`.

Для сборки демо из исходников в PowerShell нужен Go 1.25 или новее:

```powershell
$env:GOOS = "windows"
$env:GOARCH = "amd64"
$env:CGO_ENABLED = "0"
go build -trimpath -ldflags="-s -w" -o PoleDemo.exe main.go
```

## Запуск сервера

В каталоге проекта выполните:

```sh
docker compose up -d --build
```

Откройте http://localhost:8080. Доски хранятся в SQLite в томе Compose `boards`. Обычный перезапуск и обновление образа сохраняют данные. Команда `docker compose down -v` удаляет том и все доски.

Без Docker нужен Node.js 24 или новее. Выполните `npm start`. Устанавливать пакеты не нужно. По умолчанию база создаётся в `data/pole.sqlite`. Путь можно задать через `DATA_FILE`.

## Свой сервер

1. Скопируйте проект на сервер с Docker и Compose. Создайте в каталоге проекта файл `.env` со строкой `POLE_PASSWORD=ваш_длинный_случайный_пароль`. Логин для входа — `pole`. Если переменная пустая, приложение доступно без пароля.
2. Запустите `docker compose up -d --build`. Порт 8080 по умолчанию доступен только на самом сервере.
3. Направьте домен на сервер и настройте HTTPS через обратный прокси. Например, для Caddy, запущенного на хосте:

```caddyfile
board.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

Замените `board.example.com` на свой домен. У приложения один общий набор досок и один пароль. Совместное редактирование в реальном времени и отдельные учётные записи не реализованы. При конфликте между вкладками редактор позволяет скачать локальный вариант и открыть версию с сервера.

Для резервной копии остановите сервис командой `docker compose stop`. Скопируйте содержимое каталога `/data` из контейнера, включая все файлы SQLite:

```sh
docker compose cp pole:/data ./pole-backup
docker compose start
```

Для восстановления остановите сервис и поместите содержимое копии обратно в том `boards` по пути `/data`, сохранив права записи для контейнера. Экспорт JSON в интерфейсе сохраняет отдельную доску. Импорт JSON пока не реализован.

## Редактор

Выберите инструмент и щёлкните на холсте, чтобы добавить объект. Перетягивайте объекты, меняйте размер за нижний правый маркер и редактируйте текст двойным щелчком. Шрифт, размер и цвет настраиваются в панели объекта. Доска сохраняется автоматически. Пробел с перетаскиванием перемещает холст, а Ctrl/⌘ с колесом меняет масштаб.

Manrope, Golos Text, PT Serif, Comfortaa и IBM Plex Mono поставляются в WOFF2 и загружаются с того же сервера. Лицензии шрифтов находятся в `font-licenses/`.
